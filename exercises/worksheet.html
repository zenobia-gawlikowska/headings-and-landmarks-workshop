Audit worksheet

Audit the broken page with your screen reader’s headings and landmarks lists. Copy this checklist into your notes, or print the page.

Part 1: Headings

  1. Write down every heading in order, with its level (for example “h2 Programme”).
  2. Is there exactly one h1? Is it the topic of the page?
  3. Are any levels skipped going down (h1 → h3, h2 → h4)?
  4. Are there empty headings, or headings that don’t describe what follows?
  5. Is there text that looks like a heading but isn’t announced as one?
  6. Read only the headings: could you find the opening hours from them?

Part 2: Landmarks

  1. List every landmark and its label (for example “navigation, Main”).
  2. Is there one main landmark? Does it hold the main content?
  3. Are the header, primary navigation, search and footer exposed as landmarks?
  4. Are there two landmarks of the same type that sound the same?
  5. Is any content outside every landmark?

Part 3: Fixes

For each problem, write the fix as one line of HTML. Example:

Problem: page title is a <div class="t-page">
Fix:     <h1 class="t-page">Autumn Reading Festival 2026</h1>

Part 4: Compare

Click “Show page structure” on the broken page to see what the inspector finds, then open the fixed page and check the answers.
